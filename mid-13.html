GWS 검증 시나리오 2 중급 MID-13

Sheets 데이터 확인, 보호 범위 설정, 알림 규칙을 활용한 안정적인 공동 입력 양식 운영

여러 담당자가 동시에 입력하는 시트에서 잘못된 값 입력이나 수식 훼손을 사전에 방지하고, 데이터 변경 사항을 실시간 알림으로 추적할 수 있는지 확인해 보세요.

대상 서비스
Google Sheets
필요 에디션
제한 없음 조건부 알림은 Business Standard 이상
예상 소요
50분
난이도
중

사전 준비

  • 계정시트 소유자 1개 + 공동 입력자 2개 (보호 범위 차단 동작 확인용)
  • 샘플 데이터공동 입력 시트 1개 — 입력 영역 8열, 계산 영역은 별도 시트로 분리
  • 선행드롭다운 목록에 쓸 부서·상태 값을 별도 시트에 미리 만들어 둡니다. 직접 입력보다 유지보수가 쉽습니다
  • 주의알림 메일은 소유자 본인 계정으로만 발송됩니다. 다른 사람에게 보내려면 Apps Script 가 필요합니다

단계별 수행 전체 9단계

01

여러 사람이 함께 쓸 시트를 만들 때는, 동료들이 직접 입력하는 '입력 영역'과 수식이 계산되는 '계산 영역' 시트를 따로 분리해 주는 것이 훨씬 안전합니다.

02

메뉴에서 '데이터' > '데이터 확인' > '규칙 추가'를 눌러 부서명이나 처리 상태 열에 깔끔한 드롭다운 목록을 적용해 보세요.

03

날짜나 숫자 범위 조건 규칙을 설정한 뒤, 조건에 맞지 않는 값이 들어올 경우 '잘못된 데이터 거부' 옵션을 지정해 잘못된 입력을 차단하세요.

04

이메일이나 전화번호 입력 칸에는 REGEXMATCH 맞춤 수식을 써보세요. 텍스트 정규식을 통해 유효한 형식인지 꼼꼼히 체크할 수 있습니다.

05

'데이터' > '보호된 시트 및 범위' 메뉴를 선택하여 계산 공식 영역의 수정 권한을 지정 관리자로 제한합니다.

보호는 두 종류입니다. 경고 표시는 수정 시 확인창만 띄우고, 특정 사용자만 편집은 실제로 차단합니다. 목적에 맞게 골라야 합니다.

06

조건부 서식을 지정해 보세요. 입력이 누락된 필수 항목 셀이 눈에 띄는 색으로 강조되어 동료들이 빼먹지 않고 작성하도록 도와줍니다.

07

'도구' > '알림 설정 ' 메뉴에서 수정 시 즉시 메일 발송을 지정하거나, '도구' > '조건부 알림'을 사용해 셀 범위별 맞춤 알림을 설정해 보세요.

도구 › 알림 설정은 시트 전체 변경을, 도구 › 조건부 알림은 특정 조건일 때만 발송합니다. 후자가 실무에서 훨씬 쓸모 있습니다.

08

열 머리글에 작성 요령을 메모나 댓글로 친절히 적어두고, 이슈가 있는 셀에는 '@멘션'으로 담당자를 지정해 확인을 부탁해 보세요.

09

'파일' > '버전 기록' 또는 개별 셀 마우스 우클릭 > '수정 기록 표시'를 활용해 보세요. 데이터의 이전 값과 수정한 작성자를 투명하게 확인할 수 있습니다.

셀 우클릭 › 수정 기록 표시는 그 셀 하나의 변경 이력만 보여 줍니다. 버전 기록보다 정밀합니다.

확인 방법 최종 결과 2개

일부러 잘못된 값을 입력하면 거부되고, 보호 영역을 수정하려 하면 실제로 차단됩니다.

데이터 변경 조건이 발생했을 때 내 메일함으로 알림 메일이 잘 도착하는지 확인해 보세요.

자주 겪는 오류

잘못된 값을 넣었는데 그냥 들어감
'잘못된 데이터에 대해' 옵션이 경고 표시로 되어 있습니다. 실제로 막으려면 입력 거부로 바꿔야 합니다. 경고는 빨간 삼각형만 붙이고 값은 저장합니다.
보호를 걸었는데 동료가 수정함
경고 표시 방식으로 보호한 경우입니다. 확인창에서 계속을 누르면 수정됩니다. 실제 차단은 특정 사용자만 편집으로 설정해야 합니다.
알림 메일이 안 옴
알림은 시트 소유자 본인에게만 발송됩니다. 다른 사람에게 보내려면 Apps Script 의 MailApp 이 필요합니다(UC14·UC17 참고). 또한 본인이 직접 한 변경에는 알림이 오지 않습니다.
조건부 알림 메뉴가 없음
Business Standard 이상에서 제공됩니다. 하위 등급에서는 일반 알림 설정만 가능합니다. 해당없음으로 판정하고 필요 에디션을 비고에 남깁니다.
REGEXMATCH 규칙이 전부 거부됨
맞춤 수식은 범위의 첫 셀 기준으로 작성해야 합니다. =REGEXMATCH(D2,"^[\w.]+@[\w.]+$") 처럼 상대 참조로 쓰고, 범위를 D2:D 로 지정합니다.
수정 기록에 아무것도 안 보임
수식 결과 셀에는 수정 기록이 남지 않습니다. 직접 입력한 셀에서만 조회됩니다. 또 오래된 기록은 보관 기간이 지나면 사라집니다.

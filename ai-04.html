기간 단위로 자동 생성되는 수신 메일 브리프 — Workspace Studio 버전

받은 메일을 하나씩 열어보지 않아도, 지정한 기간의 메일이 문서 파일 형태의 브리프 한 장으로 자동 정리되어 매일 또는 매주 전달되는 흐름을, 코드 작성 없이 Workspace Studio만으로 구현할 수 있는지 확인해 보세요.

대상 서비스
Workspace Studio(노코드)
필요 에디션
Business Starter 이상 Workspace Studio는 Business/Enterprise 계열 에디션에 포함됩니다. AI 작업(이메일 요약 등)에는 Gemini for Workspace 라이선스가 추가로 필요합니다
예상 소요
30분
난이도
중

사전 준비

  • 계정담당자 계정 1개. Gemini for Workspace 라이선스가 활성화되어 있어야 합니다
  • 권한관리 콘솔에서 Workspace Studio 서비스가 켜져 있어야 합니다
  • 샘플 데이터브리프에 포함할 테스트 메일 몇 건, 브리프를 받을 수신자 이메일
  • 환경Chrome 최신 버전, studio.workspace.google.com

단계별 수행 전체 9단계

01

Workspace Studio(studio.workspace.google.com)에 접속하여 '새 Flow'를 생성합니다.

02

'시작 조건 선택'에서 "일정에 따라"를 선택하고, 매일 오전 7시 반복으로 지정하세요.

요일 지정 반복(예: 매주 월요일)도 같은 화면에서 고를 수 있습니다.

03

오른쪽 위 '단계 추가'에서 AI 작업 중 '읽지 않은 이메일 요약하기'를 선택하세요.

04

프롬프트에 주요 안건 / 회신이 필요한 건 / 기한이 있는 요청 / 단순 참조 네 가지 분류 기준과 출력 형식을 입력하세요.

05

'문서 만들기' 단계를 추가해 이전 단계의 이메일 요약을 Google Docs 문서로 기록하도록 설정하세요. '변수' 버튼으로 이전 단계의 출력을 문서 내용을 추가합니다.

06

'이메일 보내기' 단계를 추가해 수신자와 제목을 지정하고, '변수' 버튼으로 이전 단계의 문서 이름·문서 링크를 메시지에 추가하세요.

'변수' 버튼으로 끼워 넣은 문서 이름·링크는 이전 단계 결과가 바뀌면 메일 내용도 자동으로 함께 바뀝니다.

07

하단의 '테스트 실행'을 클릭해 샘플 메일 데이터로 전체 흐름을 미리 실행하고, 4가지 분류와 문서·메일 생성이 의도대로 되는지 확인하세요.

08

결과가 확인되면 '사용 설정'을 클릭해 Flow를 활성화하세요.

09

주간 브리프가 필요하면 이 Flow를 복제한 뒤, '일정에 따라' 단계의 반복 주기를 매주로, 이메일 요약 단계의 요약 기간을 최근 7일로 바꿔 별도 Flow로 등록하세요.

확인 방법 최종 결과 2개

테스트 실행 결과 문서에서 4가지 분류가 실제 메일 내용과 맞게 나뉘어 있고, '사용 설정'으로 Flow를 켠 이후 지정한 시각에 실제로 문서 생성·메일 발송이 이루어지는지 확인합니다.

관리자 콘솔의 Workspace Studio 활동 로그에서 흐름이 정상적으로 반복 실행되고 있는지 확인합니다.

자주 겪는 오류

Workspace Studio 메뉴 자체가 안 보임
관리자가 관리 콘솔에서 Workspace Studio 서비스를 켜지 않은 상태일 수 있습니다. 관리자에게 서비스 활성화를 요청하세요.
'단계 추가'의 AI 작업 목록에 원하는 항목이 없음
계정에 Gemini for Workspace 라이선스가 없으면 AI 작업 카테고리 자체가 비어 있을 수 있습니다. 라이선스 할당 여부를 확인하세요.
테스트 실행은 성공했는데 실제 일정에 실행이 안 됨
'사용 설정'을 누르지 않았을 가능성이 큽니다. Flow 상단에서 활성화 여부를 다시 확인하세요.

GWS 검증 시나리오 2 중급 MID-11

Sheets IMPORTRANGE 및 QUERY 함수를 활용한 여러 부서 데이터 자동 통합 집계

각 부서별로 나누어 관리되던 시트 데이터를 하나의 중앙 시트로 실시간 불러와 통합하고, 원하는 조건에 맞춰 자동으로 요약 집계할 수 있는지 확인해 보세요.

대상 서비스
Google Sheets
필요 에디션
제한 없음 전 에디션
예상 소요
55분
난이도
상

사전 준비

  • 계정본인 계정 1개 + 원본 시트 접근 권한이 없는 동료 계정 1개 (Step 9 확인용)
  • 샘플 데이터부서별 원본 시트 3개. 열 구조를 날짜·부서·항목·수량·금액 으로 완전히 동일하게 맞춥니다
  • 선행각 원본 시트의 URL 을 미리 복사해 둡니다. IMPORTRANGE 는 전체 URL 또는 시트 ID 를 인자로 받습니다
  • 주의금액 열은 숫자 형식이어야 합니다. 텍스트로 들어가면 sum() 이 0 을 반환합니다

단계별 수행 전체 9단계

01

부서별 원본 Google Sheets 문서 3개를 준비하고, 날짜, 부서, 항목, 수량, 금액 순서로 모든 시트의 열 레이아웃 구조를 똑같이 통일해 주세요.

02

통합용 시트를 생성하고 IMPORTRANGE 수식을 작성하여 첫 번째 원본 시트의 데이터를 호출합니다.

=IMPORTRANGE("URL", "시트1!A1:E") 형태입니다. 범위 끝 행을 비워 두면 데이터가 늘어나도 자동으로 따라옵니다.

03

수식을 넣었을 때 셀에 #REF! 오류가 뜨면 당황하지 마시고 셀 위에 마우스를 올린 뒤 나타나는 '액세스 허용' 버튼을 꾹 눌러 연동 권한을 승인해 줍니다.

최초 1회는 반드시 '액세스 허용'을 눌러야 합니다. 누르기 전에는 #REF! 가 뜹니다. 오류가 아니라 승인 대기 상태입니다.

04

중괄호 배열 수식({IMPORTRANGE(...); IMPORTRANGE(...)})을 활용해 보세요. 세 개의 원본 데이터를 밑으로 차곡차곡 이어 붙일 수 있어요.

05

QUERY 함수를 사용하여 "=QUERY({IMPORTRANGE(...); IMPORTRANGE(...)}, "select Col2, sum(Col5) group by Col2")" 수식을 구성합니다.

QUERY 에서 IMPORTRANGE 결과를 다룰 때는 헤더명이 아니라 Col1·Col2 표기를 씁니다. 헤더명을 쓰면 파싱 오류가 납니다.

06

QUERY 구문 안의 조건절이 특정 셀(예: 조회 기간 입력 셀)을 바라보게 만들어 보세요. 셀의 날짜나 값을 바꿀 때마다 요약 결과가 즉시 알아서 변경됩니다.

07

각 부서 원본 시트에 새 행을 추가하거나 숫자를 수정해 보세요. 통합 시트로 데이터가 실시간으로 잘 받아와지는지 확인합니다.

08

IFERROR 와 ARRAYFORMULA 함수를 수식에 결합해 보세요. 데이터가 없을 때 생기는 에러를 방지하고 새로운 데이터가 들어와도 수식이 알아서 적용됩니다.

09

원본 시트 접근 권한이 없는 다른 동료 계정으로 통합 시트를 열어보세요. 데이터가 보안 문제없이 안전하고 깔끔하게 표출되는지 테스트해 줍니다.

확인 방법 최종 결과 1개

부서 원본 3개 시트의 금액 총합과 통합 시트 QUERY 요약 결과 수치를 직접 대조해 보세요. 차이가 정확히 0으로 똑같은지 확인합니다.

자주 겪는 오류

#REF! 가 사라지지 않음
액세스 허용을 누르지 않았거나, 원본 URL 이 잘못된 경우입니다. 수식이 있는 셀을 클릭해야 허용 버튼이 뜹니다. 셀을 클릭하지 않으면 버튼이 나타나지 않습니다.
QUERY 에서 파싱 오류
헤더명을 그대로 쓴 경우입니다. IMPORTRANGE 결과에는 헤더 인식이 없으므로 Col1·Col2 표기를 써야 합니다. 열 번호는 가져온 범위 기준이지 원본 시트 기준이 아닙니다.
sum() 결과가 0
금액 열이 텍스트 형식입니다. 원본에서 숫자 형식으로 바꾸거나, 통화 기호·쉼표가 텍스트로 들어갔는지 확인합니다. 앞뒤 공백도 원인이 됩니다.
행을 추가했는데 통합 시트에 안 나옴
IMPORTRANGE 범위를 A1:E500 처럼 고정했기 때문입니다. A1:E 로 끝 행을 비워 두면 자동으로 확장됩니다.
동료가 통합 시트를 열었는데 빈 화면
원본 시트 권한이 없기 때문이며 정상 동작입니다. 통합 시트만 공유해서는 데이터가 보이지 않습니다. 원본에도 최소 뷰어 권한을 주거나, 값 복사본을 별도로 배포해야 합니다.
시트가 자주 느려짐
IMPORTRANGE 는 원본을 주기적으로 다시 읽습니다. 원본이 크거나 개수가 많으면 지연이 커집니다. 필요한 열만 가져오도록 범위를 좁히고, 집계 결과만 별도 시트에 값으로 고정하는 방법을 검토합니다.

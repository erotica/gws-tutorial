GWS 검증 시나리오 2 고급 ADV-03

Google Chat 대화형 앱(봇) 개발 및 명령어 처리

Google Chat 대화형 앱을 개발하여 스페이스 내 슬래시 명령어 기반의 업무 조회 및 처리 인터랙션을 구현하는 방법을 습득합니다.

대상 서비스
Google Chat, Google Apps Script
필요 에디션
Business Standard 이상 Chat 앱은 Starter 미지원 · GCP 프로젝트 필요
예상 소요
120분
난이도
상

사전 준비

  • 역량JavaScript + JSON 스키마 이해. cardsV2 는 구조가 까다로워 문서를 옆에 두고 작업합니다
  • 권한Google Cloud 프로젝트 생성 권한과 Chat API 사용 설정 권한이 필요합니다. 조직 정책상 막혀 있으면 진행 불가입니다
  • 계정개발자 1개 + 봇과 대화할 사용자 2개 + 테스트 스페이스 1개
  • 주의Apps Script 기본 프로젝트로는 안 됩니다. 표준 GCP 프로젝트로 전환해야 Chat API 를 붙일 수 있습니다

단계별 수행 전체 9단계

01

Google Apps Script 프로젝트를 생성하고, Chat 앱 이벤트 수신 및 처리를 위해 표준 Google Cloud 프로젝트(GCP) 프로젝트 번호와 바인딩 연동을 설정합니다.

확인 Apps Script 프로젝트가 표준 GCP 프로젝트에 연결되고 프로젝트 번호가 표시됩니다.
02

GCP 콘솔에서 Google Chat API를 활성화하고, Chat 앱 프로필 정보(앱 이름, 아바타 이미지 URL, 상세 설명) 및 배포 구성을 완료합니다.

Chat API 구성 화면에서 앱 이름·아바타·설명과 연결 설정(Apps Script 배포 ID) 을 지정합니다. 이 화면이 봇의 관제탑입니다.

확인 Chat API 구성 화면에 앱 이름·아바타·설명이 저장되고 상태가 사용 가능으로 바뀝니다.
03

Chat 스페이스/1:1 대화방에서 사용자 메시지 수신 시 호출되는 onMessage(event) 이벤트 핸들러 함수를 구현하고 페이로드 데이터를 추출합니다.

확인 봇에게 보낸 메시지가 onMessage 로 들어오고 응답이 돌아옵니다.
04

Chat API 구성 페이지에서 슬래시 명령어(Slash Commands)를 등록하고, 각 명령어 ID(commandId)에 따른 서버 실행 스크립트 라우팅 분기 로직을 작성합니다.

슬래시 명령어는 코드가 아니라 Chat API 구성 화면에서 등록합니다. 등록하지 않으면 / 를 쳐도 목록에 안 뜹니다.

확인 / 를 입력하면 등록한 명령어 목록이 자동완성으로 뜹니다.
05

cardsV2 규격의 대화형 카드 응답 객체를 설계하여 버튼, 텍스트 입력 필드, 드롭다운 메뉴 등 대화형 UI 위젯 컴포넌트를 구성합니다.

cardsV2 는 스키마가 엄격합니다. 필수 필드가 빠지면 오류 없이 조용히 무시되고 빈 응답이 갑니다.

확인 카드 형태로 제목·본문·버튼이 렌더링됩니다. 텍스트로만 보이면 스키마 오류입니다.
06

CardService 인터랙션 이벤트(CARD_CLICKED) 및 폼 제출 핸들러를 구현하여 사용자의 대화형 카드 조작에 따른 후속 처리 및 카드 갱신 로직을 수행합니다.

확인 버튼을 누르면 onCardClick 이 실행되고 카드가 갱신되거나 후속 메시지가 옵니다.
07

Chat 앱이 스페이스에 추가(ADDED_TO_SPACE)되거나 제거(REMOVED_FROM_SPACE)되는 이벤트를 감지하여 최초 진입 시 사용 안내 카드 메시지를 자동 전송합니다.

확인 스페이스에 앱을 추가하면 안내 메시지가 자동 발송됩니다.
08

외부 REST API 연동 서비스 또는 Google Sheets 원천 데이터베이스를 연동하여 실시간 업무 조회 결과를 카드 응답 컴포넌트에 매핑합니다.

확인 Sheets·외부 API 조회 결과가 응답에 반영됩니다.
09

Chat 앱 배포 범위를 조직 내 특정 도메인 또는 사용자 테스터 그룹으로 제한 설정하여 안전한 시범 운영 권한 제어를 구사합니다.

확인 지정한 사용자·그룹만 앱을 찾고 추가할 수 있습니다.

확인 방법 최종 결과 2개

1:1 대화방과 스페이스 각각에서 슬래시 명령어 10회가 모두 정상 응답합니다.

응답 지연 시간이 2초 이내로 측정됩니다.

자주 겪는 오류

봇에게 말을 걸어도 반응이 없음
Chat API 구성의 배포 ID 가 최신이 아닐 가능성이 큽니다. 코드를 고쳤으면 새 배포를 만들고 그 ID 로 갱신해야 합니다. 코드만 저장해서는 반영되지 않습니다.
GCP 프로젝트를 연결할 수 없음
Apps Script 기본 프로젝트로는 Chat API 를 붙일 수 없습니다. 프로젝트 설정에서 표준 GCP 프로젝트로 전환해야 하며, 조직 정책상 GCP 프로젝트 생성이 막혀 있으면 관리자 협조가 필요합니다.
/ 를 쳐도 명령어가 안 나옴
슬래시 명령어는 Chat API 구성 화면에서 등록해야 합니다. 코드에 분기만 만들어 두면 자동완성에 나타나지 않습니다.
카드가 텍스트로만 보임
cardsV2 스키마 오류입니다. cardId·card.sections·widgets 구조가 정확해야 하며, 하나라도 빠지면 조용히 무시됩니다. 단순 text 응답부터 확인한 뒤 단계적으로 카드를 붙이세요.
버튼을 눌러도 아무 일이 없음
onCardClick 핸들러가 없습니다. 버튼 클릭은 onMessage 로 들어오지 않는 별도 이벤트입니다. 함수명은 onClick.action.function 에 적은 값과 일치해야 합니다.
응답이 가끔 안 옴
Chat 은 3초 안에 응답을 기대합니다. 외부 API 조회가 느리면 타임아웃됩니다. 즉시 임시 응답을 보내고 결과는 별도 메시지로 보내는 비동기 패턴으로 바꾸세요.

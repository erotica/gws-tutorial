GWS 검증 시나리오 2 초급 BAS-04

Google Sheets 데이터 입력 및 기본 함수·차트 활용

Google Sheets를 통한 기초 데이터 입력, 수식·함수 활용, 데이터 필터링 및 차트를 활용한 데이터 시각화 방법 습득

대상 서비스
Google Sheets
필요 에디션
제한 없음 전 에디션
예상 소요
30분
난이도
하

사전 준비

  • 계정본인 계정 1개 + 동시 입력 확인용 동료 계정 1개
  • 샘플 데이터10행 이상 입력할 내용 — 날짜·항목·수량·금액 정도면 충분합니다
  • 환경브라우저만 있으면 됩니다. Excel 이 설치되어 있지 않아도 됩니다
  • 주의숫자는 숫자로 입력하세요. 앞에 공백이나 따옴표가 붙으면 텍스트가 되어 계산이 되지 않습니다

단계별 수행 전체 9단계

01

Google Drive에서 [새로 만들기 > Google 스프레드시트]를 선택합니다.

확인 새 시트가 열리고 A1 셀에 커서가 있습니다.
02

헤더를 구성하고 데이터를 입력합니다.

확인 머리글 행과 10행 이상의 데이터가 입력됩니다.
03

셀 표시 형식(통화, 날짜, 백분율)을 설정합니다.

확인 통화·날짜·백분율 서식이 적용되어 표시가 바뀝니다. 수식 입력줄의 원래 값은 그대로입니다.
04

SUM, AVERAGE 등 기본 계산 함수를 적용합니다.

함수는 = 로 시작합니다. =SUM( 까지 치면 도움말이 뜨므로 외울 필요가 없습니다.

확인 SUM·AVERAGE·COUNT 결과가 나타납니다. 값이 0 이면 숫자가 텍스트로 들어간 것입니다.
05

채우기 핸들을 드래그하여 수식을 자동 복사합니다.

확인 채우기 핸들을 끌면 수식이 아래 행까지 복사되고, 참조가 한 칸씩 내려갑니다.
06

필터를 생성하고 조건별 데이터를 추출합니다.

필터는 데이터를 지우는 것이 아니라 잠시 숨기는 것입니다. 해제하면 다시 보입니다.

확인 필터를 걸면 조건에 맞는 행만 남고, 열 머리글에 깔때기 표시가 붙습니다.
07

막대 차트를 삽입하고 제목과 축을 설정합니다.

범위를 선택한 뒤 삽입 › 차트를 누르면 자동으로 유형을 추천합니다.

확인 차트가 삽입되고 제목·축 이름을 지정할 수 있습니다.
08

시트 탭을 추가하고 이름과 색상을 변경합니다.

확인 시트 탭이 추가되고 이름·색상이 바뀝니다.
09

편집자 권한으로 공유하고 동시 입력을 진행합니다.

확인 동료와 동시에 입력해도 서로의 입력이 실시간으로 보입니다.

확인 방법 최종 결과 2개

함수 계산 결과가 수기로 계산한 값과 일치합니다.

데이터를 추가하면 차트가 자동으로 갱신됩니다.

자주 겪는 오류

SUM 결과가 0 으로 나옴
숫자가 텍스트로 입력된 경우입니다. 셀에서 값이 왼쪽 정렬이면 텍스트입니다. 앞뒤 공백이나 쉼표·원 표시를 지우고 다시 입력하세요.
필터를 걸었더니 데이터가 사라짐
사라진 것이 아니라 숨겨진 것입니다. 열 머리글의 깔때기 아이콘을 눌러 모두 선택하면 다시 보입니다.
채우기 핸들을 끌었는데 값이 복사만 됨
수식이 아니라 값을 끈 경우입니다. 수식이 든 셀을 선택하고 우측 하단의 작은 네모를 끌어야 합니다. 수식 안의 참조가 한 칸씩 내려가면 정상입니다.
차트가 데이터를 추가해도 안 바뀜
차트 데이터 범위가 A1:D11 처럼 고정된 경우입니다. 차트 편집기에서 범위를 A:D 로 바꾸면 추가된 행까지 따라옵니다.
날짜를 넣었는데 숫자로 바뀜
날짜 서식이 아닌 상태입니다. 서식 › 숫자 › 날짜를 지정하면 제대로 보입니다. 반대로 45231 같은 숫자가 보이는 것도 같은 이유입니다.
동료 입력이 안 보임
동료에게 편집자 권한이 있어야 합니다. 뷰어면 입력 자체가 안 됩니다. 우측 상단 접속자 아이콘으로 함께 열려 있는지 확인하세요.

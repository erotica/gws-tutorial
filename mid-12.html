GWS 검증 시나리오 2 중급 MID-12

Sheets 피벗 테이블, 조건부 서식, 차트를 조합한 한눈에 보는 실적 분석 대시보드 제작

원시 데이터를 피벗 테이블, 차트, 조건부 서식과 조합하여 직관적인 실적 분석 대시보드로 시각화하고, 이를 의사결정에 효과적으로 활용할 수 있는지 확인해 보세요.

대상 서비스
Google Sheets
필요 에디션
제한 없음 전 에디션
예상 소요
50분
난이도
중

사전 준비

  • 계정본인 계정 1개
  • 샘플 데이터원시 데이터 300행 이상 — 날짜·부서·항목·수량·금액·목표 열. 최소 6개월치가 있어야 월별 추세가 보입니다
  • 선행머리글 행을 보기 › 고정 › 1행으로 고정해 두면 이후 작업이 훨씬 수월합니다
  • 주의피벗·차트 범위를 A1:F300 처럼 고정하면 데이터 추가 시 갱신되지 않습니다. 열 전체(A:F) 로 지정합니다

단계별 수행 전체 9단계

01

원시 데이터(Raw data) 시트를 데이터베이스 표 형태로 깔끔하게 정돈하고, 맨 위 머리글 행이 움직이지 않도록 '틀 고정'을 적용해 주세요.

02

상단 메뉴에서 '삽입' > '피벗 테이블'을 선택해 보세요. 클릭 몇 번으로 부서별·월별 실적 요약 보고서 틀이 짠하고 완성됩니다.

피벗 편집기가 우측에 열립니다. 행에 부서, 열에 월, 값에 금액을 넣으면 교차표가 만들어집니다.

03

피벗 테이블 값(Value) 설정에서 단순 합계뿐만 아니라 '전체 대비 비율(%)'도 함께 표시하도록 설정해 한눈에 비중을 파악해 보세요.

04

피벗 테이블 또는 차트 선택 후 '데이터' > '슬라이서 추가' 메뉴를 실행하여 동적 대화형 필터를 적용해 보세요.

05

조건부 서식의 '색상 스케일' 기능을 적용해 보세요. 실적이 높고 낮은 구간이 알록달록 시각적으로 명확하게 들어옵니다.

색상 스케일은 값의 크기를 색 농도로 보여줍니다. 숫자를 읽지 않아도 상·하위 구간이 눈에 들어옵니다.

06

'맞춤 수식'을 이용해 조건부 서식을 만들어 보세요. 목표 실적에 미달하는 항목이 있는 경우 해당 행 전체의 배경색을 강조해 시선을 집중시킬 수 있습니다.

07

'삽입' > '차트' 메뉴에서 영역 막대와 달성률 선을 동시에 보여주는 콤보 차트를 만들고, 오른쪽에 보조 축을 추가하여 세련되게 꾸며보세요.

콤보 차트는 금액(막대)과 달성률(선)처럼 단위가 다른 두 지표를 함께 볼 때 씁니다. 선 계열에 보조 축을 지정해야 제대로 보입니다.

08

정성껏 만든 차트들을 '대시보드'라는 이름의 별도 시트로 모아서 보기 좋게 레이아웃을 다듬어 줍니다.

09

데이터 추가 시 자동 확장되도록 참조 범위를 'A:F' 형태의 오픈 렌지로 설정해 둡니다.

확인 방법 최종 결과 1개

신규 1개월분 데이터를 시트에 새로 넣어보세요. 피벗 테이블, 차트, 조건부 서식이 알아서 착착 업데이트되고 계산 수치도 일치하는지 확인합니다.

자주 겪는 오류

데이터를 추가했는데 피벗이 안 바뀜
피벗 데이터 범위가 A1:F300 처럼 고정된 경우입니다. 편집기에서 범위를 A:F 로 바꾸면 자동 확장됩니다. 열 전체 지정 시 빈 행은 자동으로 무시됩니다.
슬라이서 메뉴를 못 찾겠음
삽입이 아니라 데이터 › 슬라이서 추가 입니다. 또한 차트나 피벗 테이블을 선택한 상태여야 대상에 연결됩니다. 빈 셀에서 추가하면 범위를 직접 지정해야 합니다.
조건부 서식이 셀 하나만 칠함
맞춤 수식에서 열 고정 $ 이 빠졌습니다. 행 전체를 칠하려면 =$F2<$G2 처럼 열만 고정하고 행은 상대 참조로 둡니다.
콤보 차트에서 선이 안 보임
보조 축을 지정하지 않아 금액 스케일에 눌린 것입니다. 계열 설정에서 해당 계열의 축을 우측 축으로 바꿉니다.
총계 대비 비율이 이상하게 나옴
'총계 대비'의 기준이 행·열·전체 중 무엇인지 확인합니다. 값 필드의 요약 기준을 잘못 고르면 합이 100%가 되지 않습니다.
피벗에 월이 아니라 날짜가 그대로 나옴
날짜 열을 우클릭해 피벗 그룹 만들기 › 연-월을 선택해야 합니다. 날짜가 텍스트 형식이면 그룹이 불가하므로 먼저 날짜 형식으로 변환합니다.

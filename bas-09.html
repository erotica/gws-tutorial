GWS 검증 시나리오 2 초급 BAS-09

Google Forms 설문 제작 및 응답 확인

Google Forms를 활용한 목적별 설문지 제작, 배포, 실시간 응답 집계 및 Google Sheets 데이터 연동 분석 방법 습득

대상 서비스
Google Forms, Google Sheets
필요 에디션
제한 없음 전 에디션
예상 소요
30분
난이도
하

사전 준비

  • 계정설문 작성자 1개 + 테스트 응답용 동료 계정 2~3개
  • 샘플 설계5문항 정도의 간단한 사내 설문. 객관식·체크박스·단답형을 섞어 봅니다
  • 환경브라우저만 있으면 됩니다
  • 주의응답을 먼저 Sheets 에 연결한 뒤 테스트하세요. 나중에 연결하면 이전 응답이 안 넘어올 수 있습니다

단계별 수행 전체 9단계

01

Google Drive에서 [새로 만들기 > Google 설문지]를 선택합니다.

확인 새 설문지가 열리고 첫 질문이 하나 있습니다.
02

설문 제목 및 기본 설명을 작성합니다.

확인 제목과 설명이 상단에 표시됩니다.
03

객관식, 체크박스 등 다양한 유형의 문항을 추가합니다.

질문 유형은 우측 드롭다운에서 바꿉니다. 객관식은 하나만, 체크박스는 여러 개를 고를 수 있습니다.

확인 질문 유형을 바꾸면 입력 형태가 달라집니다. 객관식은 원형, 체크박스는 사각형입니다.
04

주요 문항을 '필수' 입력으로 설정합니다.

확인 필수로 지정한 질문에 빨간 별표가 붙고, 응답하지 않으면 제출이 막힙니다.
05

테마 색상 및 헤더 이미지를 변경합니다.

확인 테마 색상과 헤더 이미지가 적용됩니다.
06

미리보기 모드로 응답 화면을 점검합니다.

확인 미리보기에서 응답자 화면이 그대로 보이고, 실제로 응답도 해볼 수 있습니다.
07

설문 공유 링크를 생성하여 배포합니다.

확인 짧은 링크가 만들어지고 Gmail 본문에 붙여넣을 수 있습니다.
08

응답 탭에서 실시간 차트 및 내용을 확인합니다.

응답 탭에는 요약 차트가 자동으로 그려집니다. 별도 작업이 필요 없습니다.

확인 응답 탭에 응답 수와 요약 차트가 나타납니다.
09

Google Sheets와 연동하여 응답 시트를 생성합니다.

Sheets 연결은 응답 탭 우측 상단 더보기(⋮) › 응답 저장 위치 선택 에 있습니다.

확인 Sheets 가 새로 만들어지고 응답이 행 단위로 기록됩니다.

확인 방법 최종 결과 1개

테스트 응답 3건을 제출하면 설문의 응답 수와 연동된 시트의 행 수가 정확히 일치합니다.

자주 겪는 오류

Sheets 연결 메뉴를 못 찾겠음
응답 탭 우측 상단 더보기(⋮) 안에 '응답 저장 위치 선택'이 있습니다. 질문 탭에는 없으니 응답 탭으로 먼저 이동하세요.
시트 행 수가 응답 수보다 적음
Sheets 를 나중에 연결한 경우 이전 응답이 넘어오지 않을 수 있습니다. 응답 탭에서 CSV 로 내려받아 병합하거나, 테스트 전에 연결을 먼저 만드세요.
필수 항목인데 그냥 제출됨
필수 토글이 꺼져 있습니다. 질문 카드 우측 하단의 필수 스위치를 켜야 합니다. 켜지면 질문에 빨간 별표가 붙습니다.
응답자가 로그인하라고 함
설정에서 이메일 수집이나 1인 1회 제한이 켜져 있으면 로그인이 필요합니다. 익명 설문이면 두 옵션을 꺼야 합니다.
체크박스인데 하나만 선택됨
질문 유형이 객관식으로 되어 있습니다. 원형이면 객관식, 사각형이면 체크박스입니다. 유형을 바꾸면 됩니다.
링크가 너무 김
보내기 › 링크 탭에서 URL 단축 체크박스를 켜면 forms.gle/… 형태로 짧아집니다.

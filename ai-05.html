GWS 검증 시나리오 2 AI-공통 AI-05

쌓인 파일이 스스로 정리되고 질의응답으로 찾아지는 Drive

드라이브에 쌓이기만 하던 파일이 기준에 따라 정리되고, 필요할 때 설명만으로 바로 찾아지는지 확인해 보세요.

대상 서비스
NotebookLM(질의응답) + Apps Script/Gemini API(자동 재분류)
필요 에디션
제한 없음 Gemini API 키 불필요 — 키워드 사전 기반 재분류(Apps Script) + NotebookLM 질의응답, 둘 다 별도 에디션·API 키 없이 쓸 수 있습니다
예상 소요
25분
난이도
중

사전 준비

  • 계정담당자 계정 1개
  • 권한자동 재분류 코드를 실행하려면 Drive 파일 이동 권한이 있는 계정이어야 합니다
  • 샘플 데이터정리 대상 Drive 폴더 1개(주제가 섞인 문서 여러 건), 분류 기준별 키워드 목록(예: '영업' → 영업·견적·계약)
  • 환경Chrome 최신 버전, notebooklm.google.com + script.google.com

단계별 수행 전체 9단계

01

NotebookLM(notebooklm.google.com)에서 새 노트북을 생성하고, 질의응답 대상이 되는 Drive 폴더이 모든 문서들을 소스로 등록합니다.

02

"찾고 싶은 자료를 설명하면 관련 파일을 찾아준다"는 요구사항대로, 자연어로 질문을 입력해 답변과 함께 출처 파일이 표시되는지 확인합니다.

03

자동 재분류를 위해 Apps Script 편집기에서 새 프로젝트를 만들고, DriveApp으로 정리 대상 폴더의 파일 목록을 가져오는 코드를 작성합니다.

04

각 파일의 파일명과 내용 일부에 분류 기준별로 미리 정해 둔 키워드가 포함돼 있는지 검사해, 일치하는 분류를 판단하는 코드를 추가합니다.

05

판단 결과에 따라 파일을 목적지 폴더로 이동시키는 코드를 추가합니다.

06

처음에는 실제 이동 대신 "이 폴더로 이동 예정"이라는 판단 결과만 로그로 출력하도록 해, 분류 정확도를 먼저 검토합니다.

실제로 파일을 옮기기 전에 로그로만 먼저 확인하는 이유는 오분류로 파일이 엉뚱한 곳에 흩어지는 것을 막기 위해서입니다.

07

분류 정확도가 충분하다고 판단되면, 실제 이동을 실행하도록 스크립트를 전환합니다.

08

분류 기준을 바꾸고 싶을 때는 4번 단계의 기준 목록만 수정해 다시 실행하면 재분류되는지 확인합니다.

09

정리된 폴더를 다시 NotebookLM의 소스로 갱신해, 재분류 이후에도 질의응답 검색이 최신 상태를 반영하는지 확인합니다.

재분류 직후에는 NotebookLM이 예전 폴더 구조를 기억하고 있을 수 있어, 소스를 다시 동기화해야 최신 결과로 답합니다.

확인 방법 최종 결과 2개

NotebookLM에 자연어로 질문했을 때 관련 파일명이 출처로 함께 제시되고, 실제로 그 파일을 열어보면 질문 내용과 관련이 있는지 확인합니다.

자동 재분류 실행 후 각 파일이 의도한 목적지 폴더로 옮겨져 있고, 분류 기준을 바꿔 재실행했을 때 새 기준대로 다시 옮겨지는지 확인합니다.

자주 겪는 오류

NotebookLM 질문에 대한 답변에 출처가 안 나옴
소스로 등록한 폴더 안에 실제로 관련 내용이 없을 수 있습니다. 폴더 소스가 최신 상태로 등록돼 있는지 먼저 확인하세요.
자동 재분류 스크립트가 파일을 계속 '기타'로만 분류함
파일명·본문에 등록해 둔 키워드가 실제로 등장하지 않는 경우입니다. 키워드 사전은 문맥을 이해하지 못하고 글자 그대로만 비교하므로, 실제 문서에서 쓰는 표현(약어·다른 어미 등)을 키워드 목록에 추가하세요.
재분류 후 원본 폴더에 파일이 그대로 남아 있음
이동 코드가 목적지 폴더에 추가만 하고 원본 폴더에서 제거하는 단계가 빠졌을 수 있습니다. 두 단계가 모두 실행되는지 코드를 확인하세요.

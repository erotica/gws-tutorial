GWS 검증 시나리오 2 중급 MID-02

Gmail 비밀 모드를 활용한 만료일·다운로드 제한 보안 메일 발송

담당자가 외부에 민감한 자료를 보낼 때 비밀 모드로 만료일과 전달·인쇄·다운로드·복사 제한을 걸어 안전하게 발송하고, 필요하면 언제든 즉시 접근을 차단할 수 있는지 확인해 보세요.

대상 서비스
Gmail
필요 에디션
제한 없음 무료 개인 Gmail 계정도 발신 가능
예상 소요
25분
난이도
하

사전 준비

  • 계정담당자 계정 1개 + 협력사 역할로 쓸 계정 1개 (수신 화면 확인용, 시크릿 창으로 대체 가능)
  • 권한별도 관리자 권한 불필요. 무료 개인 계정을 포함한 모든 Gmail에서 발신 가능합니다
  • 샘플 데이터외부와 공유해도 무방한 첨부파일 1개
  • 환경Chrome 최신 버전, Gmail 웹 (모바일 앱은 열람은 가능하나 설정은 웹을 권장)

단계별 수행 전체 9단계

01

편지쓰기 창을 열고 하단 아이콘 중 자물쇠 모양의 '비밀 모드 사용 설정'을 클릭하세요.

02

만료일을 '1주'로 지정하고, 추가 인증 방법은 '인증 필요 없음'으로 둔 뒤 '저장'을 누르세요.

만료일은 1일·1주·1개월·3개월·1년·5년 중에서만 고를 수 있습니다. 임의의 날짜는 지정할 수 없습니다.

03

받는사람에 외부 협력사 이메일 주소를 입력하고, 공유해도 무방한 자료를 첨부한 뒤 메일을 보내세요.

04

방금 보낸 메일을 다시 열어, 본문 하단에 만료일이 표시된 비밀 모드 배지가 남아 있는지 확인하세요.

05

협력사 계정이나 시크릿 창으로 메일을 열어, 전달·인쇄·다운로드·복사 아이콘이 모두 비활성화된 화면으로 보이는지 확인하세요.

06

수신자 화면에서 첨부파일을 열어보고, 별도 뷰어 창으로만 열리고 로컬 저장은 되지 않는지 확인하세요.

첨부파일은 다운로드되지 않고 별도 뷰어 창으로만 열립니다. 로컬에 사본이 남지 않습니다.

07

보낸편지함으로 돌아와 해당 메일을 열고 '액세스 취소'를 눌러, 만료일 전이라도 즉시 열람을 차단할 수 있는지 확인하세요.

08

액세스를 취소한 뒤 협력사 화면을 새로고침해, 내용이 사라지고 만료·차단 안내만 남는지 확인하세요.

09

사내에서 반복해서 보내는 보안 메일이 있다면 서명 아래에 '기밀 자료는 비밀 모드로만 발송합니다' 같은 안내 문구를 등록해 다음부터 빠뜨리지 않고 챙길 수 있는지 확인해 보세요.

서명 아래 안내 문구 등록은 선택 사항입니다. 반복적으로 보안 메일을 보내는 업무에서만 유용합니다.

확인 방법 최종 결과 1개

협력사 화면에서 전달·다운로드·인쇄·복사가 모두 막혀 있고, 액세스 취소 이후에는 내용 자체가 보이지 않는지 확인합니다.

자주 겪는 오류

비밀 모드 아이콘이 안 보임
관리자가 관리 콘솔에서 비밀 모드 사용을 차단한 조직 계정일 수 있습니다. 관리 콘솔 › 앱 › Google Workspace › Gmail › 사용자 설정에서 허용 여부를 확인하세요.
만료일이 지났는데도 계속 열림
브라우저 캐시 때문일 수 있습니다. 새로고침 후에도 열리면 만료 처리가 서버에 반영되기까지 다소 지연될 수 있습니다. 급하게 차단해야 한다면 Step 7의 '액세스 취소'를 바로 사용하세요.
전달·다운로드 제한이 안 걸림
Outlook 등 Gmail이 아닌 메일 클라이언트로 열람한 경우 제한이 온전히 강제되지 않을 수 있습니다. 수신자에게 Gmail 웹이나 앱으로 열어달라고 안내하세요.
'액세스 취소' 버튼이 안 보임
대화 목록 미리보기가 아니라 메일을 직접 열어야 상단에 나타납니다. 보낸편지함에서 해당 메일을 클릭해 들어가세요.
SMS 인증을 선택했는데 수신자가 인증코드를 못 받음
SMS 인증에는 수신자의 전화번호가 필요합니다. 상대방 번호를 모른다면 '인증 필요 없음'으로 바꿔 다시 발송하세요.

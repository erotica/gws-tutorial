GWS 검증 시나리오 2 중급 MID-06

Drive for desktop 및 오프라인 액세스를 활용한 유연한 하이브리드 작업 환경 구축

PC 탐색기나 인터넷이 연결되지 않은 오프라인 환경에서도 Drive 파일을 열어 자유롭게 편집하고, 네트워크가 연결되면 충돌 없이 자동으로 동기화되는지 확인해 보세요.

대상 서비스
Google Drive
필요 에디션
제한 없음 공유 드라이브 부분은 Standard 이상
예상 소요
60분
난이도
상

사전 준비

  • 계정본인 계정 1개 + 충돌 처리 확인용 동료 계정 1개 (같은 파일에 편집 권한)
  • 권한PC 관리자 권한 필요. Drive for desktop 은 설치 시 관리자 승인을 요구합니다
  • 샘플 데이터Office 파일 2건(.docx/.xlsx) + Google 문서 2건. 오프라인 편집 대상
  • 환경네트워크를 실제로 끊을 수 있어야 합니다. Wi-Fi 토글 또는 기내 모드로 차단합니다

단계별 수행 전체 9단계

01

PC에 데스크톱용 Google Drive(Drive for Desktop)를 설치하고 조직 계정으로 로그인을 진행하세요.

02

클라우드에서 바로 열어 용량을 아끼는 '스트리밍' 방식과 컴퓨터에 항상 복사본을 두는 '미러링' 방식의 특징을 살펴보고, 나에게 맞는 동기화 방식을 선택하세요.

스트리밍은 클라우드에 두고 필요할 때만 내려받아 디스크를 아끼고, 미러링은 전부 로컬에 복제해 항상 오프라인 접근이 가능합니다. 나중에 바꿀 수 있지만 재동기화에 시간이 걸립니다.

03

내 컴퓨터의 파일 탐색기(Windows)나 Finder(Mac)를 열어보세요. Google Drive 가 새로운 드라이브 항목으로 잘 들어와 있는지 확인합니다.

04

공유 드라이브에서 자주 쓰는 작업 폴더를 마우스 우클릭한 뒤 '오프라인에서 사용 가능'을 클릭해 두세요. 인터넷이 없어도 로컬에 저장되어 언제든 열 수 있습니다.

스트리밍 모드에서도 특정 폴더만 골라 로컬에 상주시킬 수 있습니다. 이 지정을 하지 않으면 네트워크가 끊긴 순간 파일이 열리지 않습니다.

05

Google Drive 설정(톱니바퀴) 메뉴의 일반 탭에서 '오프라인' 항목을 활성화하여 오프라인 작업 환경을 등록해 주세요.

06

인터넷 Wi-Fi 연결을 살짝 끈 상태에서 MS Office 파일이나 Google Workspace 문서를 열어 자유롭게 수정 작업을 진행해 보세요.

07

인터넷을 다시 연결한 뒤 데스크톱 앱의 동기화 상태 아이콘을 확인해 보세요. 수정했던 내용들이 클라우드로 차곡차곡 자동 업로드됩니다.

08

같은 파일을 두 사람이 오프라인 상태에서 각각 수정해 보세요. 인터넷 재연결 시 충돌 파일(사본)이 자동으로 생성되어 안전하게 보존되는지 점검해 줍니다.

두 사람이 오프라인에서 같은 파일을 고치면 Drive 는 병합하지 않고 사본을 만듭니다. 어느 쪽도 소실되지 않지만 수동 병합이 필요합니다.

09

MS Office 형식 문서(.docx, .xlsx 등)를 변환 과정 없이 Drive에서 바로 열어 수정해 보세요. 원래 확장자 그대로 안전하게 저장되는지 확인합니다.

확인 방법 최종 결과 1개

문서의 '버전 기록'을 열어 오프라인 수정 시점이 구분되어 남아있는지 확인하고, 해당 버전으로 원활히 복원되는지 검증합니다.

자주 겪는 오류

설치가 관리자 권한에서 막힘
Drive for desktop 은 시스템 드라이버를 설치하므로 PC 관리자 권한이 필요합니다. 회사 정책상 설치가 불가한 환경이면 이 UC 는 해당없음으로 판정하고 사유를 비고에 남깁니다.
G: 드라이브가 안 보임
드라이브 문자가 다른 장치와 충돌한 경우입니다. Drive 환경설정에서 문자를 바꾸거나, 폴더 마운트 방식으로 전환합니다. Drive 앱이 실행 중인지도 확인하세요.
오프라인에서 Google 문서가 안 열림
Drive for desktop 과 별개 설정입니다. Chrome 에서 Docs 오프라인 확장과 오프라인 사용 설정을 켜야 합니다(Step 5). 파일 스트리밍만으로는 Google 문서가 열리지 않습니다.
네트워크 복구 후 동기화가 멈춤
트레이 아이콘에서 일시중지 상태인지 확인합니다. 계속 멈춰 있으면 로그아웃 후 재로그인하거나 앱을 재시작합니다. 파일명에 \ / : * ? " < > | 가 있으면 업로드가 실패합니다.
충돌 사본이 계속 늘어남
여러 기기에서 같은 파일을 동시에 열어 둔 경우입니다. 편집 전 동기화 완료를 확인하는 운영 규칙이 필요합니다. 사본은 자동 정리되지 않으므로 수동 삭제해야 합니다.
Office 파일이 Google 형식으로 바뀜
Drive 웹에서 열기 방식을 Google 문서로 선택한 경우입니다. Drive for desktop 을 통해 로컬 Office 앱으로 열면 원본 형식이 그대로 유지됩니다.

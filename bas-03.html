GWS 검증 시나리오 2 초급 BAS-03

Google Docs 문서 작성 및 실시간 공동 편집

Google Docs를 활용한 표준 문서 작성, 서식 적용 및 다수 인원의 실시간 동시 편집·검토 프로세스 습득

대상 서비스
Google Docs
필요 에디션
제한 없음 전 에디션
예상 소요
30분
난이도
하

사전 준비

  • 계정본인 계정 1개 + 동시 편집 확인용 동료 계정 1개. 이 UC 는 혼자서는 핵심을 볼 수 없습니다
  • 샘플 데이터삽입할 이미지 1개. 본문에 넣을 내용은 아무 텍스트나 괜찮습니다
  • 환경동료와 동시에 접속할 수 있는 시간을 미리 맞춰 두면 Step 7 이 수월합니다
  • 주의Docs 는 저장 버튼이 없습니다. 입력하는 즉시 저장되므로 저장을 찾지 마세요

단계별 수행 전체 9단계

01

Google Drive에서 [새로 만들기 > Google 문서]를 선택합니다.

확인 새 문서가 열리고 제목이 '제목 없는 문서'로 표시됩니다.
02

문서 제목을 설정하고 본문을 입력합니다.

확인 제목을 입력하면 좌측 상단 파일명이 즉시 바뀌고, 저장 버튼 없이 자동 저장됩니다.
03

글꼴, 크기, 색상 등 텍스트 서식을 적용합니다.

확인 서식이 선택한 글자에만 적용됩니다.
04

제목 스타일을 지정하고 자동 목차를 삽입합니다.

확인 제목1·제목2를 지정한 뒤 목차를 삽입하면 해당 제목들이 목록으로 나타납니다.
05

이미지와 표를 첨부합니다.

확인 이미지와 표가 본문에 삽입되고 크기를 조절할 수 있습니다.
06

동료에게 편집자 권한으로 문서를 공유합니다.

확인 동료 이름이 공유 목록에 추가되고 편집자로 표시됩니다.
07

동료와 실시간으로 동시에 접속하여 함께 편집합니다.

두 사람이 동시에 접속해야 합니다. 서로의 커서에 이름이 붙어 실시간으로 움직이는 것이 이 UC 의 핵심입니다.

확인 동료의 커서에 이름이 붙어 실시간으로 움직이고, 입력하는 글자가 바로 보입니다.
08

댓글을 작성하고 답글을 주고받은 뒤 완료 처리합니다.

댓글은 문장을 선택한 뒤 우측에 나타나는 말풍선 아이콘으로 답니다.

확인 댓글이 우측에 카드로 나타나고, 답글 후 해결 처리하면 카드가 접힙니다.
09

PDF 또는 Word(.docx) 형식으로 다운로드합니다.

다운로드는 사본을 내려받는 것이고, 원본 Docs 는 그대로 남습니다.

확인 PDF·Word 파일이 다운로드되고, 열어 보면 서식이 유지되어 있습니다.

확인 방법 최종 결과 2개

파일 > 버전 기록에 변경자 이름과 수정 시각이 나열됩니다.

이전 버전을 선택해 복원하면 문서가 그 시점 상태로 되돌아갑니다.

자주 겪는 오류

저장 버튼이 안 보임
Docs 에는 저장 버튼이 없습니다. 입력하는 즉시 자동 저장되며, 상단에 '드라이브에 저장되었습니다'가 잠깐 표시됩니다. 정상 동작입니다.
목차가 비어 있음
제목 스타일을 지정하지 않았기 때문입니다. 글자를 크게·굵게 한 것만으로는 목차에 잡히지 않습니다. 제목 1·제목 2 스타일을 적용한 뒤 목차를 새로고침하세요.
동료 커서가 안 보임
두 사람이 동시에 문서를 열고 있어야 합니다. 한 명이 닫으면 커서가 사라집니다. 우측 상단에 접속자 아이콘이 몇 개인지 확인하세요.
Word 로 받아 고쳤는데 원본에 반영 안 됨
다운로드는 사본입니다. 원본과 연결되지 않습니다. 반영하려면 고친 Word 파일을 Drive 에 다시 올려 Docs 로 변환해야 합니다.
댓글을 해결했더니 사라짐
삭제된 것이 아니라 접힌 것입니다. 우측 상단 댓글 기록 아이콘에서 해결된 댓글까지 모두 볼 수 있습니다.
버전 기록에 이름이 안 나옴
익명 편집자로 표시되는 경우는 로그인하지 않은 사용자가 링크로 편집했을 때입니다. 조직 계정으로 접속하면 이름이 기록됩니다.

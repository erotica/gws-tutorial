GWS 검증 시나리오 2 중급 MID-14

Sheets 매크로 기능과 Apps Script를 활용한 반복적 데이터 집계 업무 자동화

매주 매월 반복되는 복잡한 데이터 정돈, 집계, 보고 작업을 매크로와 자동화 스크립트로 처리하여 수작업에 소요되는 시간을 획기적으로 줄일 수 있는지 확인해 보세요.

대상 서비스
Google Sheets, Google Apps Script
필요 에디션
제한 없음 Apps Script 는 전 에디션
예상 소요
70분
난이도
상

사전 준비

  • 계정본인 계정 1개. 메일 발송 확인용 수신 주소 1개
  • 권한관리 콘솔에서 Apps Script 사용이 허용되어 있어야 합니다. 차단 시 편집기 진입이 막힙니다
  • 샘플 데이터주간 집계 대상 원시 데이터 200행 이상. 매주 늘어나는 형태여야 자동화 효과가 드러납니다
  • 주의MailApp 발송에는 1일 한도가 있습니다(Workspace 기준 1,500통). 테스트 반복 시 소진에 주의하세요

단계별 수행 전체 9단계

01

'확장 프로그램' > '매크로' > '매크로 기록'을 선택한 뒤 정렬, 필터, 서식 작업을 수행하고 매크로를 저장합니다.

02

매크로 이름을 알아보기 쉽게 적고 단축키를 지정해 보세요. 지정한 단축키를 눌렀을 때 아까 했던 똑같은 작업이 순식간에 재현되는지 확인합니다.

03

'확장 프로그램' > 'Apps Script' 메뉴로 이동해 보세요. 방금 내가 기록한 매크로가 깔끔한 JavaScript 코드로 자동 변환되어 저장되어 있습니다.

매크로는 별도 기능이 아니라 Apps Script 함수로 변환되어 저장됩니다. 편집기에서 열면 그대로 코드입니다.

04

코드에서 고정되어 있던 시트 이름과 셀 범위(예: "A1:B10")를 상황에 맞춰 유연하게 바뀌는 동적 참조 변수로 살짝 개선해 줍니다.

05

스크립트에 로직을 조금 추가해 보세요. 최종 요약 데이터를 요약 시트에 알아서 모아주고 실행한 날짜와 시간(타임스탬프)까지 기특하게 남겨줍니다.

06

Apps Script의 MailApp 서비스를 활용해 스크립트를 확장해 보세요. 집계된 요약 결과를 담당자 메일로 자동 발송해 주는 편리한 기능이 완성됩니다.

07

Apps Script 좌측의 시계 아이콘('트리거') 메뉴에서 매주 정해진 시각에 자동 구동되는 시간 기반(Time-driven) 트리거를 구성해 주세요.

트리거는 코드가 아니라 편집기 좌측 시계 아이콘에서 등록합니다. 코드만 작성하고 트리거를 빠뜨리면 자동 실행되지 않습니다.

08

스크립트를 처음 실행할 때 권한 동의 창이 나타납니다. 안내 메시지를 따라 '허용'을 차근차근 누르고 권한 동의 절차를 마치시면 됩니다.

09

Apps Script의 '실행 기록' 대시보드로 들어가 보세요. 자동화 스크립트가 에러 없이 잘 실행되었는지, 소요 시간은 얼마나 걸렸는지 모니터링할 수 있습니다.

실행 기록에서 성공·실패와 소요 시간을 확인합니다. 실패 원인은 여기서만 볼 수 있습니다.

확인 방법 최종 결과 2개

2주간 트리거로 자동 실행된 집계 수치와 직접 수기 작업으로 집계한 수치를 대조해 보세요. 완벽하게 일치하는지 확인합니다.

자동화 기능을 도입하기 전과 후의 소요 시간을 비교해 보세요. 얼마나 많은 업무 시간이 절약되었는지 구체적인 수치로 확인해 봅니다.

자주 겪는 오류

Apps Script 편집기가 안 열림
관리 콘솔에서 Apps Script 가 차단된 상태입니다. 앱 › 추가 Google 서비스 › Apps Script 에서 허용해야 합니다. 사용자가 해결할 수 없으므로 관리자 요청이 필요합니다.
'확인되지 않은 앱' 경고에서 막힘
본인이 만든 스크립트에는 정상적으로 뜨는 화면입니다. 고급 › 안전하지 않은 페이지로 이동을 눌러 진행합니다. 조직 정책으로 차단된 경우에는 관리자가 앱을 신뢰 목록에 넣어야 합니다.
트리거를 걸었는데 실행이 안 됨
실행 기록을 먼저 봅니다. 대부분 권한 재승인 필요 또는 시트명 변경이 원인입니다. 트리거는 조용히 실패하므로 로그 확인이 유일한 방법입니다.
메일이 발송되지 않음
OAuth 동의 시 메일 전송 권한이 포함되지 않았을 수 있습니다. 트리거를 삭제하고 다시 등록해 재승인합니다. 1일 발송 한도 소진도 확인하세요.
매크로가 다른 시트에서는 오작동
기록된 코드에 시트명·범위가 하드코딩되어 있기 때문입니다. Step 4 의 일반화를 건너뛰면 반드시 발생합니다. getActiveSheet() 와 getLastRow() 로 바꿉니다.
실행 시간이 초과됨
Apps Script 는 실행당 최대 6분(Workspace 기준 30분) 제한이 있습니다. 셀 단위 반복 대신 getValues() 로 한 번에 읽고 setValues() 로 한 번에 쓰면 대폭 빨라집니다.

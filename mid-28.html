GWS 검증 시나리오 2 중급 MID-28

Google AppSheet 노코드 플랫폼을 활용한 현장 점검 및 재고 관리 모바일 앱 제작

현업 담당자가 기존 Sheets 데이터를 기반으로 모바일 앱을 직접 제작하여, 현장 데이터 수집 및 재고 관리 업무를 쉽고 빠르게 디지털화할 수 있는지 확인해 보세요.

대상 서비스
Google AppSheet, Google Sheets
필요 에디션
AppSheet Core 이상 메일·스케줄 봇은 유료 구독 필요
예상 소요
80분
난이도
상

사전 준비

  • 계정앱 제작자 1개 + 현장 사용자 계정 2개 (보안 필터 확인용)
  • 라이선스Enterprise Standard·Plus 에는 AppSheet Core 가 포함됩니다. Business 계열은 별도 구독이 필요할 수 있습니다
  • 샘플 데이터품목·수량·위치·점검일 열을 가진 Sheets 1개. 첫 행은 반드시 머리글이어야 합니다
  • 환경모바일 기기 1대. 사진·바코드·GPS 는 실기기에서만 확인됩니다

단계별 수행 전체 9단계

01

현장에서 관리할 데이터 항목들(품목명, 수량, 점검 상태, 사진 등)을 Google Sheets 시트에 표 형태로 깔끔하게 먼저 작성하세요.

02

AppSheet(appsheet.com)에 접속하여 Google 계정으로 로그인한 뒤, 만들어둔 Sheets를 연결해 새 앱을 생성합니다.

시트를 고르면 AppSheet 가 열 구조를 읽어 앱 뼈대를 자동 생성합니다. 빈 화면에서 시작하지 않습니다.

03

AppSheet 에디터의 Data > Columns 메뉴에서 각 열의 Data Type을 Image, Date, Ref, Enum 등으로 알맞게 설정하세요.

04

UX 메뉴로 들어가 모바일 화면 디자인을 선택하세요. Deck, Table, Form 등 알맞은 화면 레이아웃을 고르고 정렬 필터를 정해줍니다.

뷰는 목록(Table)·상세(Detail)·입력 폼(Form) 세 종류가 기본입니다. 현장 앱은 폼이 가장 중요합니다.

05

데이터 검증 수식(Valid_If)이나 필수 작성(IsRequired) 설정을 적용해 보세요. 현장 담당자가 값을 누락하거나 잘못 작성하는 것을 방지해 줍니다.

06

앱에 스마트폰 카메라 촬영, 바코드/QR코드 스캔, GPS 위치 좌표 자동 수집 컬럼을 추가해 보세요. 현장 점검 업무가 몇 배 더 빨라집니다!

사진·바코드·GPS 는 열 유형을 바꾸면 자동으로 활성화됩니다. 별도 코드가 필요 없습니다.

07

왼쪽 메뉴 Security->클릭, 상단 보안 필터(Security Filter) 설정을 적용해 보세요. 작업자 계정 권한에 따라 본인이 담당하는 구역의 데이터만 노출되도록 제어할 수 있습니다.

08

Automation 탭에서 자동화 Bot을 만들어 보세요. 재고 수량이 설정한 기준 아래로 떨어지면 경고 메일이나 Chat 메시지가 자동으로 전송됩니다. (유료 플랜 필요)

09

완성된 앱을 현장 팀원들의 이메일로 공유하세요. 스마트폰에 AppSheet 앱을 설치한 뒤 배포받은 앱을 열어 구동 테스트를 완료해 줍니다.

확인 방법 최종 결과 2개

현장에서 앱으로 점검 데이터 20건을 입력해 보세요. Sheets 원본에 바로 잘 들어가며, 인터넷이 안 터지는 오프라인 상태에서 입력한 내용도 재연결 시 정상 동기화되는지 확인합니다.

일부러 재고를 기준치 이하로 줄여보세요. 지정된 담당자에게 알림 메일이나 메시지가 즉시 잘 도착하는지 체크합니다.

자주 겪는 오류

앱 생성이 안 되거나 라이선스 오류
Enterprise Standard·Plus 에는 AppSheet Core 가 포함되지만 Business 계열은 별도 구독이 필요할 수 있습니다. 라이선스가 없으면 해당없음으로 판정하고 필요 구독을 비고에 남깁니다.
사진 열에서 카메라가 안 열림
열 유형이 Image 가 아니라 Text 로 잡힌 경우입니다. Data › Columns 에서 직접 바꿉니다. 자동 인식은 자주 틀립니다.
Ref 열이 드롭다운으로 안 보임
참조 대상 테이블이 앱에 추가되지 않았습니다. Data 에서 대상 시트를 먼저 테이블로 추가한 뒤 Ref 를 지정해야 합니다.
알림 봇이 실행은 되는데 메일이 안 감
이메일 발송과 스케줄 이벤트 봇은 유료 구독 기능입니다. 무료·기본 범위에서는 봇이 실행되어도 메일이 나가지 않습니다. 판정 시 제약으로 명시해야 합니다.
다른 담당자 구역 데이터가 보임
보안 필터가 적용되지 않았습니다. Security › Security Filters 에서 [담당자] = USEREMAIL() 형태의 조건을 걸어야 합니다. 뷰 필터는 보안이 아니라 표시 조정일 뿐입니다.
오프라인 입력이 사라짐
앱 설정에서 오프라인 사용을 켜야 합니다. 또 동기화 전에 앱을 삭제하거나 캐시를 지우면 로컬 데이터가 사라집니다. 현장 운영 규칙에 동기화 확인을 포함하세요.

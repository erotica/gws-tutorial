GWS 검증 시나리오 2 중급 MID-09

Docs 스마트 칩, 빌딩 블록, 문서 탭을 활용한 프로젝트 문서 통합 관리

흩어지기 쉬운 회의록, 업무 현황, 관련 자료를 하나의 Docs 문서 안에서 스마트 칩과 문서 탭으로 깔끔하게 구조화하여 관리할 수 있는지 확인해 보세요.

대상 서비스
Google Docs
필요 에디션
제한 없음 문서 탭은 전 에디션
예상 소요
45분
난이도
중

사전 준비

  • 계정본인 계정 1개 + 동시 편집 확인용 동료 계정 2개
  • 샘플 데이터연결할 Drive 문서 2~3건, 앞으로 예정된 Calendar 회의 일정 1건 (스마트 칩 연동 대상)
  • 선행사람 칩은 조직 내 계정만 인식합니다. 외부 주소는 칩이 아니라 일반 텍스트로 남습니다
  • 환경Docs 웹. 문서 탭 패널이 접혀 있으면 좌측 상단 목록 아이콘으로 펼칩니다

단계별 수행 전체 9단계

01

Google Docs 문서 작성 화면 좌측의 '문서 탭' 패널에서 개요, 회의록, 이슈 등 필요한 탭을 3개 이상 생성해 보세요.

문서 탭은 한 파일 안의 여러 문서입니다. 별도 파일이 아니므로 공유·권한이 문서 단위로 한 번에 적용됩니다.

02

생성한 각 문서 탭 아래에 세부 하위 탭(Subtabs)을 추가해 보세요. 2단계 깊이의 알차고 깔끔한 계층 구조를 완성할 수 있습니다.

03

본문 작성 중 '@' 기호를 입력해 인물 스마트 칩을 넣고 이름을 선택해 보세요. 마우스를 올렸을 때 해당 동료의 프로필 카드가 짠하고 나타납니다.

04

'@' 기호를 누르고 파일 이름을 검색해 파일 스마트 칩을 추가해 보세요. 연관된 Google Drive 파일의 링크와 미리보기가 예쁘게 연동됩니다.

파일 칩은 미리보기가 딸린 링크입니다. 단순 URL 붙여넣기와 달리 제목·소유자·썸네일이 함께 표시됩니다.

05

'@' 입력 후 Google Calendar 일정을 검색하여 스마트 칩으로 삽입하면 회의 명칭, 일시, 참석자 데이터가 연동됩니다.

06

'@'를 누르거나 빌딩 블록 메뉴에서 '회의록' 템플릿을 불러와 보세요. 참석자 목록과 안건을 기재할 수 있는 양식이 자동으로 깔끔하게 생성됩니다.

회의록 빌딩 블록은 캘린더 일정을 고르면 참석자와 날짜가 자동으로 채워집니다. 빈 템플릿이 아닙니다.

07

빌딩 블록에서 '검토 추적기'나 '제품 로드맵' 표를 추가해 보세요. 드롭다운 칩(진행 중, 완료 등)을 활용해 상태를 원활하게 관리할 수 있어요.

08

표 안에 할 일 체크리스트를 만들고 동료를 담당자로 지정해 보세요. 해당 사용자의 Google Tasks로 할 일이 자동으로 연결되어 동기화됩니다.

09

문서 목차(TOC)를 자동 생성해 보고, 특정 탭의 전용 주소(URL)를 복사해 접속해 보세요. 클릭하자마자 해당 탭 위치로 바로 이동하는지 테스트합니다.

확인 방법 최종 결과 1개

팀원 3명이 서로 다른 탭에 동시에 접속해 수정 작업을 해보세요. 충돌 없이 내용이 실시간 반영되고 스마트 칩 데이터도 최신으로 잘 업데이트되는지 확인합니다.

자주 겪는 오류

@ 를 쳐도 사람 칩이 안 나옴
조직 외부 주소이거나 디렉터리에 없는 계정입니다. 외부 주소는 칩이 되지 않고 일반 텍스트로 남습니다. 이는 제품 사양이므로 불합격 사유가 아닙니다.
문서 탭 패널이 안 보임
좌측 상단 목록 아이콘으로 펼칩니다. 아이콘 자체가 없으면 브라우저를 새로고침하거나, 이전 버전 Docs 인터페이스를 쓰고 있는지 확인합니다.
3단계 하위 탭이 안 만들어짐
문서 탭은 2단계까지만 지원합니다. 더 깊은 구조가 필요하면 문서를 나누고 파일 칩으로 연결하는 편이 낫습니다. 제품 제약이므로 비고에 남깁니다.
회의록 블록에 참석자가 안 채워짐
캘린더 일정을 선택하지 않고 빈 회의록을 삽입한 경우입니다. 삽입 시 일정 선택 단계를 거쳐야 자동 입력됩니다. 지난 일정은 목록에 나타나지 않을 수 있습니다.
체크리스트 담당자가 Tasks 에 안 뜸
할당은 되었지만 담당자 본인 계정에서 확인해야 합니다. 작성자 화면에는 나타나지 않습니다. 또한 담당자에게 문서 편집 권한이 있어야 할당이 성립합니다.
탭 링크를 공유했는데 첫 탭이 열림
탭 링크는 탭을 우클릭해 탭 링크 복사로 얻어야 합니다. 주소창 URL 을 그대로 복사하면 문서 첫 탭으로 연결됩니다.
